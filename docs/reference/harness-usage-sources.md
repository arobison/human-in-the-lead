# Usage sources by harness

A dated reference note for [design part 12.5](../design/0001-human-in-the-lead/12-reporting-and-limits.md#125-quotas-and-budgets). The design describes the model. This note holds the vendor details, which change often.

**Status.** Read from vendor documentation on 2026-11-14. Plan names, prices, field names and API behavior were not rechecked after that date, and some claims were not independently verified. Check the linked pages before relying on any line.

## What each account exposes

| Account | Machine-readable | Not machine-readable |
|---|---|---|
| **Claude subscription** (Pro, Max, Ultra) used through Claude Code | The status line command's JSON input carries `rate_limits.seven_day`, and `rate_limits.five_hour` on plans with a five-hour window, each with `used_percentage` and `resets_at`, once a session has made its first request. Pro and Max plans have both windows; verified Ultra accounts have only the weekly one (rechecked 2026-11-16). Each window may be absent, and Claude Code drops one once it resets. It is a per-session feed to a status line command, not an API. The adapter installs a status line command (or wraps the owner's) that appends a snapshot to the metrics store | The `/usage` command and the apps' Settings > Usage page show limits, but only on screen. No documented API exposes remaining subscription quota. Limits are percentages with no published token equivalent |
| **Claude Code tokens and cost**, any account | OpenTelemetry metrics (`claude_code.token.usage` by type and model; `claude_code.cost.usage`) exported to a local collector or file; headless `claude -p --output-format json` results include `total_cost_usd`. Costs are client-side estimates at list price | Session transcript files: their format is documented as internal and changing between versions, so the system does not parse them for usage |
| **Anthropic API keys** | The Usage and Cost Admin API (buckets of a minute, an hour or a day; data typically within 5 minutes; needs an admin key); the newer Usage and Cost Analytics API (beta; refreshed within hours); the Claude Code Analytics API (daily, per actor; excludes subscription use); rate-limit response headers; spend limits set in the Console, which return a specific error when reached | — |
| **GitHub Copilot** | Since 2026-06-01, usage is billed in AI credits (1 credit = $0.01) with a monthly allowance per plan, resetting at 00:00 UTC on the 1st (some annual plans keep premium requests). REST usage endpoints report AI-credit usage per user or organization, at daily granularity. User-level budgets stop usage when reached. The cloud agent also uses Actions or cloud compute minutes, a separate allowance | Intraday remaining credits: shown in the VS Code status bar, not documented as an API |
