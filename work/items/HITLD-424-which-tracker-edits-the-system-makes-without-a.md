## Question

Accept the proposed default list of two-way-door tracker edits (create an item, fix wording inside an item's facts, add or correct a needs link, correct a duplicate), with everything else staying the owner's?

HITLD-143 turns today's standing sign-off for tracker-only merges into a person setting.

## Options and recommendation

- A. Accept the list: Each change is logged, listed in the digest with its reversing command, reversible by a revert PR; one setting turns it off; executors cannot use it.
- B. Add milestone placement: Also placing an existing item under an existing milestone.
- C. Narrower: create items only: Only creating items and recording the owner's answers.

Recommended: Accept the list. The chief of staff recommended it.
