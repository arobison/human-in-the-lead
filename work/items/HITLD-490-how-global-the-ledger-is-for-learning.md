## Question

How global should the ledger be for learning?

The owner wants a global ledger across the whole system for learning. Each project has its own private store and confidentiality class.

## Options and recommendation

- A. Per project, plus shared learned figures: Each project keeps its own raw ledger; a person-level layer holds only aggregates (estimates, token ratios, trust calibration); no raw events cross projects.
- B. One global ledger of raw events: Every event from every project of the owner in one union.
- C. Per project only: As designed: learning stays inside each project.
- D. Tell me more first: What each lets the estimator and trust record learn.

Recommended: Per project, plus shared learned figures. The chief of staff recommended it.
