## Question

Keep the error code name no-pull-request for approving a branch that has no open pull request?

PR 622 adds one public error code. It matches no-run, no-worktree and no-precedent; not-presented and not-waiting mean something different.

## Options and recommendation

- A. Keep no-pull-request: The name says exactly what is missing and matches the other no-... codes.
- B. Rename to not-presented: Reuses an existing code that means the queue has not shown the PR.

Recommended: Keep no-pull-request. The chief of staff recommended it.
