## Question

Should every question to the owner be filed as a pending decision in the tracker before the box is shown?

Staying in the harness (HITLD-540), the worst failure is a question box dropped by a worker restart, which happened about a dozen times in three days.

## Options and recommendation

- A. File first, then ask: Before each question the chief of staff writes a pending decision (question, options, recommendation); a dropped box is re-asked on resume from it; the owner's answer closes it
- B. Keep re-asking from memory: No pending record
- C. Only for decisions that matter: File first only for design-changing or budget-spending questions

Recommended: File first, then ask. The chief of staff recommended it.
