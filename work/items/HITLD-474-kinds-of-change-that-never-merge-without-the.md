## Question

Which kinds of change should never merge without the owner's own yes, whatever the history?

Under the risk-first rule (HITLD-473), one-way doors always wait. The owner picks which kinds those are.

## Options and recommendation

- A. All four always wait: Data formats; public interface and policy; skills, hooks and agent contracts; security and rights.
- B. Fewer than four: The owner names which of the four may ever unlock.

Recommended: All four always wait. The chief of staff recommended it.
