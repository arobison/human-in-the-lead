## Question

How long is the rung-2 veto window, and does it run while the owner is asleep?

HITLD-505: rung 2 is tell the owner, then proceed unless they object within a window. HITLD-291 left open the window and how the owner is told and objects.

## Options and recommendation

- A. Awake-time window, set per kind: Counted in the owner's awake time (quiet hours pause it), set per kind in the signed commitment decision, default 4 hours; the owner objects by any reply or by putting the item on hold, which stays held at every rung; silence proceeds only after the window
- B. Fixed wall-clock window: A plain 1 hour on the clock
- C. No timer: until acknowledged: Proceeds once seen, which is rung 1 again

Recommended: Awake-time window, set per kind. The chief of staff recommended it.
