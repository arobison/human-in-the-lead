## Question

Should answers resolved by a precedent the owner set earlier count as recorded answers when a delegated merge checks a decision answer?

PR #207 (HITLD-150): merge authority holds on the pull request path.

## Options and recommendation

- A. Yes, they count: A precedent-resolved answer is a recorded owner answer.
- B. No, only direct answers: A PR changing a precedent-resolved answer waits for the owner.

Recommended: Yes, they count. The owner created the precedent; the answer is theirs.
