## Question

What does HITLD give a project's own app to build on the shared contract?

Owner wants most projects to reuse the base UI as is, and a few to restyle it, add information, change the information architecture, or write their own UI over the contract.

## Options and recommendation

- A. Client plus React components: A framework-free typed client plus React components for the six panel types in one package.
- B. Typed client only: A validated reader only; each project draws its own UI.
- C. Contract only: No package.

Recommended: Client plus React components. The chief of staff recommended it.
