## Question

What should the chief of staff do when it runs into a problem with the system?

In the first self-hosted run the chief of staff met several problems (a dropped relay, notifications read late, a store status that stays due after a push) and filed some only when the owner pointed them out. Raised for HITLD-155, which covers how agents raise the bugs and emergent work they find.

Reversibility: two-way.

## Options and recommendation

- A. Search the tracker, file if nothing covers it, and say so: The chief of staff checks the work items for the problem, files one if none covers it (proposed when the fix is a design choice), and tells the owner in one line what it filed.
- B. Ask the owner before filing: The chief of staff describes the problem and waits for the owner to say to file it.
- C. Only report it: The chief of staff tells the owner about the problem and files nothing.

Recommended: Search the tracker, file if nothing covers it, and say so. It keeps problems from being lost and costs the owner no attention.
