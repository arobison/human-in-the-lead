## Question

Is earned trust per project, or does it carry across the owner's projects?

HITLD-507 and HITLD-472: a kind's evidence (aged clean merges, commitments finished within budget) is about one project's code, checks and work. HITLD-470 and 492: the ledger is per project with person-level aggregates for learned figures only.

## Options and recommendation

- A. Per project, carried by proposal: Trust is earned and recorded in each project's own record; in another project the system may propose the same unlock citing the first project's evidence, and the owner decides
- B. Per person, across projects: Trust earned in one project applies to all
- C. Per project, never carried: Each project earns it from zero

Recommended: Per project, carried by proposal. The chief of staff recommended it.
