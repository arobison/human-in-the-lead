## Question

Should an answer's validity depend on a proof the system can check, instead of on which channel it arrived through?

Today an answer counts only if it came through the chief of staff's own session, because the harness guarantees that turn is the owner's (HITLD-407). A web page cannot give that guarantee. HITLD-333, 409 and 501 (signed answers, contributors) and HITLD-508 (a service as a decision surface) all depend on this.

## Options and recommendation

- A. Channel-neutral proof: One answer record with a proof field: the harness-attested turn today, the person's own signature later; the session, a web page or any other client only carries the proof; a web write without a proof stays data, not an answer
- B. Session only: The owner answers only in the chief of staff's session; the web is read and propose only
- C. Decide after the service study: Keep HITLD-407 as written until HITLD-508 reports

Recommended: Channel-neutral proof. The chief of staff recommended it.
