# Skills

Layer 2 sources in the `SKILL.md` format, one directory per skill ([design part 15.2](../docs/design/0001-human-in-the-lead/15-architecture.md#skills-in-the-agent-skills-format)). Portable front matter only (`name`, `description`, `license`, `compatibility`, `metadata`, `allowed-tools`); harness-specific fields are added by packaging. Skills call `hitld`, never a harness feature.

The first milestone has `orchestrate/` (the orchestrator's run loop), `chief-of-staff/` (the session the owner talks to, which starts and replaces orchestrator sessions and owns the schedule) and `execute/` (one dispatched item, per the executor contract), from piece (h). It also has `curate/` (the curator's pass over the work items after merge batches, dispatched like an executor, HITLD-132) and `adopt/` (set up a repository: inspects it, proposes the whole setup in one message, and runs it only after the owner's yes; the people's version is in [docs/guide/](../docs/guide/README.md)). `npm run build` places them in the plugin with Claude Code front matter. The others listed in design part 16.1 follow in later milestones.
